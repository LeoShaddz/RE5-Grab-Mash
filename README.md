# RE5-Grab-Mash

When grabbed by an enemy, you normally have to press the 'A' and 'D' key or controller analog stick to break free. 

This quality-of-life mod allows you to break free simply by holding the 'F' key on your keyboard or the 'A' button on your controller. The keyboard key is customizable. Also works for quick-time events that require press the 'A' and 'D' key or rotating the analog stick.
